AI 红人营销操作系统
Influencer Marketing AIOS

把「选品 → 策略 → Brief → 红人 → 寄样 → 素材 → 复盘 → 结算」做成一条有记忆、可复用、可审计的闭环工作流，让 AI 承担判断与起草，人只做确认与决策。

版本　v1.5（已实现基线）
日期　2026-09-03
形态　高保真可交互原型
市场　中国品牌出海 · 美国站
语言　中文界面；Brief 与邮件支持中英切换
导航　13 个一级模块

1. 背景与问题

中国品牌在北美做红人营销，真正的成本不在预算，而在判断与协作的损耗：选品靠感觉、策略写在文档里没人回看、Brief 每次从零开始、红人沟通散落在邮箱、素材回收靠人催、复盘结论下一轮又忘了。

这些环节各自都有工具，但彼此不连通，导致三个后果：同一个判断被反复重做；数据无法回流（复盘结论改不动选品评分与下一轮策略）；进度不可见（不知道哪一步卡住，只能靠开会同步）。

本系统的目标不是再做一个「红人管理表格」，而是做一个有记忆的操作系统：每一次判断都留下依据，每一次结果都回写到判断上。

2. 目标用户与场景

角色 核心诉求 高频动作
Marketing Lead 预算花在哪最值、进度是否失控、团队谁在拖 看 Dashboard、在 My Tasks 处理九类审批、看人员榜单
推广专员 今天该做什么、Brief 怎么写、红人怎么谈 生成策略与 Brief、建联红人、寄样、录入素材并提交打标
运营 / 选品 哪些产品值得投红人预算 查产品经营数据、看营销得分、勾选提交推广

3. 产品原则

  1. AI 负责起草，人负责确认。所有 AI 输出都可编辑、可确认、可标记不适用，并显示依据与置信度。
  2. 一切结果回写到判断。复盘结论能改产品评分、策略章节与 Brief 模板。
  3. 状态而非文档。策略与 Brief 是有版本、有审批状态的对象，不是静态文件。
  4. 分类由审核决定。素材与红人的分类不由执行人直接写入，一律走「提交 → 审核 → 收录」。
  5. 数据同源。同一概念只有一个来源——时间目标只来自时间进度调整，Dashboard 与复盘全部由各模块真实记录派生。

4. 核心流程

Products（营销得分 + 勾选推广）　→　Campaigns（新建 Campaign：营销目标、推广KPI、预算与时间）　→　Strategy Studio（八模块输入 → 生成策略 → 逐章确认）
→　Brief Studio（按渠道或红人风格生成 → 多版本保存 → 申请审核）　→　My Tasks（九类审批 · 邮件跟进）　→　Influencer CRM（筛选 / 扩量 → 首次建联 → 谈判 → 寄样）
→　Sample Mgt（寄样进度 / 创建寄样）　→　Asset Library（录入 → AI 评估 → 打标提交 → 审核收录）　→　Reports（复盘 → 一键回写）　→　Budget Mgt（佣金结算 → 发票审批 → 回写预算池）

全流程状态在 Campaigns · 推广进度看板上以七节点呈现：策略是否完成、Brief 是否通过、开场邮件是否已发、是否达成合作、素材回收比例、时间进度是否异常、目标达成率。

5. 模块需求

导航顺序：Dashboard · My Tasks · Products · Campaigns · Strategy Studio · Brief Studio · Influencer CRM · Sample Mgt · Asset Library · Budget Mgt · Reports · Contract Mgt · Settings

5.1 Dashboard

三张卡片切换：核心数据、人员榜单、红人榜单。问候语「早上好，Helen」。全部数值由真实状态派生，支持本月 / 本季度 / 本年度与自定义区间。所有 AI 总结统一为缩放格式（徽章 + 一句摘要 + 展开/收起）。

  • 核心数据：进行中种草项目、月度曝光量完成率、累计合格素材数、待回收素材、平均 CPV、预算支出、寄样总数量、待回复邮件；上方为可缩放的「核心数据诊断」。
  • 目标完成概览：五项目标（合格素材数、曝光数、红人 GMV、CPV 达成率、UGC 授权素材）对比时间进度刻度线。
  • 合作漏斗：与目标完成概览同构，每环节给当前值 / 目标值与完成百分比；第一环节为「建联数量」。
  • 四张质量卡：流程健康、内容质量、成本效率、资产与关系沉淀；各卡独立时间维度 + 缩放 AI 总结。
  • 人员榜单：按工作流程顺序——建联数、达成合作数、寄样数、合格素材数、曝光量达成、红人 GMV、CPV、黑名单/淘汰数；上方为「人员表现诊断」。
  • 红人榜单：红人 + 层级列（Nano→Mega，与 CRM 同源）、素材主题、封面（跳原素材）、渠道、合作产品、SKU、Views、ER、CPV、红人 GMV；后四项支持升降排序；上方为「红人表现诊断」。

5.2 My Tasks

  • 卡住流程的事：六个卡片一行——待回复邮件、待回收素材、待审批事项、待补内容授权、逾期交付红人、待审批发票。
  • 待回复邮件：数据看板 + 筛选（回复状态、邮件状态 12h/24h/48h/超 48h、红人层级、红人标签）；点「去回复」直达该红人的邮件会话（与会话同源，不再出现"无往来"）。
  • 审批清单（九类）：选品、Campaign、Strategy、Brief、红人合作、寄样、素材入库、付款、合同变更。每条带类型徽章与状态徽章，「查看」按类型跳转对应模块；筛选行含审批类型与审批状态两组；驳回必须填意见（含快捷话术）；结果回流对应模块与提醒；可撤回重审（发票为双向同步）。

5.3 Products

三张卡片：产品库、红人 GMV 概况、产品异动分析。

  • 产品库：20 条 SKU 表格 + 卡内 SKU 搜索；字段含序号、营销得分、产品图、产品名、市场、品牌、店铺、BU、品类、运营专员、ASIN（跳亚马逊）、SKU、优先级（P0–P2 / K0–K2）、目标星级、星级（升降箭头）、Review、客单价、RPS14、BSR 位置、大类排名、库存、推广勾选。
  • 营销得分：AI 十维评分；推荐组合中的红人层级采用 CRM 统一分级。
  • 红人 GMV 概况：缩放 AI 总结在标题下方；表格按产品图 / 产品名称 / SKU 分列，含红人 GMV（带环比趋势）、占该产品销售、订单数、红人数、ROAS；四个指标列均支持升降排序，支持月 / 季 / 年切换。
  • 产品异动 AI 分析：预警 / 机会 / 观察三类，副标题按标签实时统计，每条可展开分析。
  • 勾选「推广」提交后，自动进入 Strategy Studio 待生成列表、Campaigns 进度看板与新建 Campaign 的产品下拉。

5.4 Campaigns

三张卡片：推广进度看板、Campaign 列表、时间进度调整；AI 总结置于三张卡片下方。三张卡片的产品集合与时间信息完全同源。

  • 推广进度看板：产品级七节点，节点可点击跳转；时间进度节点只由共享排期判定（素材逾期归入素材回收节点），未排期显示「未排期」。
  • Campaign 列表：深色方形序号 + 产品名称 + 营销目标标签（爆品打造 / 品牌打造 / 新品起量 / 常规走量）+ 状态与阶段进度；下方 4 列 × 3 行产品资料（品牌、市场、SKU、上市时间、运营专员、星级与目标星级及箭头、Review、客单价、RPS14、BSR 位置、大类排名、推广专员）；底部三栏推广KPI / 预算目标 / 时间目标，标签与数值同源，区分按期推进 / 排期落后 / 常设项目 / 已结项 / 未排期。
  • 新建 Campaign：独立页面跳转。产品 SKU 与营销目标均为下拉（SKU 仅列已勾选推广的产品），选中后自动带出产品库资料（只读）；手动填写营销目标、推广KPI、营销预算、起止时间；创建后写入列表与预算池。
  • 时间进度调整：每行显示「产品名 / SKU · Campaign 名 / 起止 · 负责人」；五阶段甘特，每阶段独立「编辑时间」，支持整体 ±1 周与复位；改期即时传导到看板与列表。

5.5 Strategy Studio

  • 三张卡片：待生成推广策略的产品 List、Create Strategy、策略库。
  • 产品选择器：序号、产品图、产品名 + ASIN + SKU、星级与 Review、市场/品牌/店铺、营销得分、策略进度；按钮为「查看策略 / 编辑策略」、「资料完整度」、「AI 解析」、「制作 Brief」。
  • 八模块输入：字段独立编辑与确认，可标记不适用；AI 提取项显示来源。推广目标下的「主目标（营销目标）」为四选一下拉（与新建 Campaign 一致，无自由文本入口），且策略正文的执行摘要与「项目目标与成功标准」按所选目标生成；每个产品的输入与目标独立保存，互不串味。
  • 策略生成：快速版 8 章 / 标准版 15 章 / 深度版 19 章，逐章确认与锁定，支持导出策略 PDF。
  • 策略库：与 Brief 库同构，横轴下拉筛选，按产品一行，「查看策略」下拉选版本并呈现完整策略文档。

5.6 Brief Studio

  • 生成设置：生成方式（按渠道 / 按红人风格）+ 语言切换（中文 / English，整份切换）+ 生成次数与已保存版本数。
  • Brief 结构（AI 生成模型）：
    ① 制作主旨 —— 让【谁】在【什么场景】里理解【一个核心信息】，并声明只需说清这一件事。
    ② 达人具体怎么拍 —— 开头（前 3 秒出现哪个场景）／展示（哪些细节需要近景 + 加分项）／表达（哪句话必须被理解，单句可念）／交付（时长、格式、静帧、时间节点）。
    ③ 边界 —— 必须保留（产品、场景、一个核心卖点、追踪）／不能出现（禁用词、过度承诺、竞品比较）／可以自由（叙事、镜头、开场、个人语气）。
    另含 Campaign 背景、内容目标、创作方向与合规提醒（含该品类可讲的事实范围）。
  • 迭代与版本：「重新生成 Brief」反复出稿；交互编辑框在正文右侧、AI 建议上方；满意后存为独立版本；表头两行布局（表头独占一行，导出与字数在第二行）。
  • Brief 库：横轴下拉筛选；按产品一行，「查看 ▾」列出各版本，每版本独立「申请审核」；被驳回版本显示意见与审批人。支持导出 Brief PDF。

5.7 Influencer CRM

五张卡片（同一行）：红人库、合作红人 List、合格/优质红人、淘汰 / 黑名单、相似度扩量。

  • 红人库：九维下拉筛选；每条横向排列，含多渠道跳转、发布频率、层级、FIT 分数（分数后紧跟「联系」，已合作显示「已合作」不可操作）；AI 分析可缩放展开，报价偏高、交付不稳定等提示并入其中。
  • FIT 打分：品牌 / 受众 / 内容 / 市场 / 目标五维，可人工修改；每维可展开明细（如受众匹配下的国家、年龄、教育、收入、地区、性别、职业分布）。
  • 建联与邮件：独立页面；合作产品下拉（取自 Brief Studio 产品列表）；语言切换仅影响主题与正文（模板名保持中文，合作类型与合作结构本地化）；七个模板——首次建联（默认，正文含产品销售链接，可「+ 添加产品 ▾」多选 SKU）、首次邮件跟进、报价与合作确认、合作确认、寄样确认、内容进度跟进、发布后数据跟进；Gmail 风格会话与收件箱同源；可发送 Brief、可发起寄样（产品 + 数量 + 美式地址）；支持立即或定时发送。
  • 合作档案：数据总结在最上方；六个加粗模块——沟通记录（可跳原邮件）、合作历史（素材可跳 Asset Library）、合同（含签约时间与正文）、付款记录（标注第几次合作与定金/尾款）、寄样记录、价格谈判记录。
  • 合格/优质红人：历史素材仅保留素材分 ≥ 60；经审批加入的素材不设门槛并标注「经审批加入」。素材分按 View 25% / GMV 30% / ROAS 25% / 目标达成 20% 计算，寄样素材（无 ROAS）按权重归一化，不被系统性低估。
  • 淘汰 / 黑名单：标注「淘汰」或「黑名单」及原因、时间、操作人，并附同结构的合作素材表。
  • 相似度扩量：以合格/优质红人为种子加权推荐；候选信息与红人库完全一致（渠道徽章、垂类、双渠道跳转、十一项信息胶囊），带相似度分与推荐理由；「加入红人库」或批量联系后自动写入红人库（状态待联系，FIT 取相似度）。
  • 批量操作：勾选后批量联系、批量寄样（自动建单）、批量打标签。

5.8 Sample Mgt

  • 顶部五个指标一行（寄样单总数、样品件数、在途、已签收、异常）；下方两张卡片：寄样进度、创建寄样。
  • 寄样进度：物流状态下拉筛选（全部 / 在途 / 已签收 / 异常，各带数量与状态色点）；异常 = 发出超过 7 天仍未签收，行内加「异常」标记并给出天数说明。
  • 创建寄样：支持单个收件人填写与批量粘贴多行地址一次建单。

5.9 Asset Library

四张卡片：Asset Library、合格素材、授权素材、录入素材。

  • Asset Library：一字段一列的扁平表格——# · 红人 · Post Day · 素材主题 · 渠道 · 封面 · 合作产品 · SKU · 合作类型 · Views · ER · CPV · 素材标签 / 红人标签 / 提交申请（三列铺开，各有表头）。筛选行：时间、产品、渠道、合作类型、Views、ER、CPV。
  • 打标与审核流程：素材标签（合格素材 / 授权素材 / 淘汰素材）与红人标签（继续合作 / 合格·优质红人 / 淘汰·拉黑）先暂存为「待提交」，点「提交申请」后进入 My Tasks 审批清单（素材入库 / 红人合作两类）；审核通过才收录到对应卡片与 CRM 名单，驳回则退回 Asset Library 可重提。
  • AI 分析：整条铺开在素材下方，一行给结论与摘要，展开后三个维度（是否达到该红人均播、CPV 是否达标、数据是否优质及建议）。
  • 合格素材：只收录审核通过的素材，行内无任何审核控件，末列为只读「收录状态」（✓ 标签 + 收录日期，悬停显示审核人）；统计口径为「命中 N 条 · ER 达标 N 条 · 已审核收录 N 条」，无收录时给出空态引导。另含数据看板、可缩放 AI 总结与五项筛选（品牌、渠道、产品、推广专员、时间）。
  • 授权素材：授权类型（广告投放授权 / 仅社媒授权）、授权期限（时长）与合同链接。
  • 录入素材：Post 日期、链接、成本 + 四个指标（Views、ER %、CPV、红人 GMV 为非必填；CPV 留空按成本 ÷ Views 自动计算）；含素材类型与授权类型选择。
  • 支持下载素材包清单（含链接与授权状态）。

5.10 Budget Mgt

  • 预算池：按产品拆分，显示预算池 / 已承诺 / 已付款 / 使用率与剩余可用。
  • 佣金结算：按归因 GMV × 佣金率计算应付佣金，一键生成发票。
  • 发票与付款审批：财务风格表单（申请人、产品、SKU、渠道、红人、付款类型首/尾款、提交时间、金额）；通过 / 驳回 / 标记已付款，付款回写预算池；与 My Tasks 审批清单双向同步。

5.11 Reports

四份报告共用骨架：标题与说明 → 四个关键指标 → AI 头条结论 → 报告主体 → 可一键写入的行动建议；均支持导出复盘 PDF。

  • Campaign 报告：花费、产出、ROAS、CPA；有效卖点与无效项；建议写入策略。
  • Influencer 报告：花费按 CRM 合作类型归类（付费 / 置换 / 佣金 / 免费 / 拒绝，未确认显示待确认并展示报价，判定取自报价与合作方式而非是否已交付）；含 Views、ER、CPV；结论列为「AI 解析」。
  • Asset 报告：按渠道互动率、按授权状态可复用比例；建议写入 Brief。
  • Product Learning：把实际表现回写到营销得分维度。

5.12 Contract Mgt / Settings

  • Contract Mgt：六份美国合同模板（付费、置换、纯佣金、免费共创、素材授权、Ambassador），中英双名称；查看与编辑默认英文正文、右上角可切中文；可删除。
  • Settings：寄样后自动跟进、AI 合规守卫、资产自动打标签、每周策略摘要、红人门户（Beta）。

6. 全局能力

  • AI 存在方式：AI 输出内联在各模块卡片中（判断 + 依据 + 置信度），全部为可缩放格式；同时提供可召唤的右侧 Copilot 面板。
  • 审核中枢：九类审批集中在 My Tasks，素材与红人分类、发票付款、选品与立项均需审核后生效，结果回流对应模块并留痕。
  • 双语能力：Brief 整份中英切换；邮件仅切主题与正文，模板名保持中文，合作类型与合作结构本地化，产品名与 SKU 保留原文。
  • 站内提醒：顶栏「提醒」带未读数，聚合红人回信（标注超 48 小时）、素材逾期、样品签收、审批结果、发票待审批，点击直达。
  • 导出与交付：策略 / Brief / 复盘导出可打印页面（存为 PDF），素材包清单导出 CSV。
  • 交互一致性：下拉点空白处自动收起、浮层不被裁切、侧栏可伸缩、同类卡片组压缩在一行、表格列宽按内容分配且不截断文本。

8. 视觉与交互规范

  • 基调：暖白纸感底色，珊瑚色为主操作色，鼠尾草绿 / 琥珀 / 砖红表示达标、注意、异常，淡紫用于 AI 输出。
  • 信息密度：中等偏专业工作台，表格化呈现，数字统一等宽对齐，列间距克制。
  • AI 视觉标识：AI 内容带徽章与依据说明，人工确认后标注「已编辑确认」。
  • 状态色义固定：草稿灰、待审批琥珀、已通过绿、已驳回红、异常砖红，全站一致。
